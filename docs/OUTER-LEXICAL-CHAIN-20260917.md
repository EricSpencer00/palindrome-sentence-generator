# Outer lexical-chain construction (2026-09-17)

This probe authorizes two independent semantic valency frames (agent, action,
patient, setting), then enumerates their lexical domains while checking the
opposite character obligations at the outer boundary. It does not reverse a
finished sentence, import catalogue prose, or score candidate outputs with a
readability reward. Every rendered row carries its two-pointer audit, hashes,
frame provenance, and the live boundary debt.

The bounded product tested 6,561 distinct frame pairs. It produced no exact
closure (longest rendered row: 55 letters). The smallest observed debt was a
two-letter mismatch, so this is a constructive diagnostic rather than a
reader candidate. The next repair is targeted domain expansion at the lexical
role owning the first mismatch, preserving both independently authored
valency frames; a larger undirected sweep would not be counted as progress.

Run with:

```text
python experiments/outer_lexical_chain_20260917.py
```
