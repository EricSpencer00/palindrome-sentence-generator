# Construction proposal: shared-character REGULAR propagation

This is an implementation proposal, not a generated-output result. It has no
new candidate, length record, or human readability evidence.

## Evidence for the change

The current live CFG and slot searches select outer words before inner words.
Their small hand-authored lexical banks rapidly force the known seed path.
Adding one terminal adjunct freezes an entire letter sequence at once; the
remaining grammar cannot pay the resulting character debt.

Several historical registry entries do not establish that a stronger solver
was tried:

* `finite_semantic_palindrome_csp_20260916.py` takes only two complete Cartesian
  product realizations and audits their rendered strings. It has no solver.
* `event_graph_character_sat_20260916.py` renders complete clause pairs before
  calculating equality rows. It has no SAT backend or domain propagation.
* `full_positional_slot_interval_csp_20260917.py` audits two complete slot
  assignments. Interval domains are listed as future work.
* `position_domain_arc_consistency_csp_20260920.py` gives every position the
  same static alphabet from its adjective/subject vocabulary. It does not
  compute position-specific grammar supports or iterate to a fixed point.

This proposal is a distinct executable search architecture relative to those
implementations, not a claim of novel constraint-programming theory.

## State and propagation

Compile a bounded, forward grammatical language into an epsilon NFA. Word
spellings are character chains. Word boundaries carry lexical IDs, number,
valency, semantic type, and parse-production provenance. Spaces and punctuation
are reconstructed from the accepted path and consume no letter positions.
Unroll optional clauses/adjuncts to a stated finite bound before determinization
or epsilon closure; never insert a known palindrome as a grammar production.

For target letter length N, maintain domains D[0..N-1] over a-z with
D[i] == D[N-1-i]. Start with all letters, subject to the grammar.

1. Compute F[i], states reachable after i characters under current D.
2. Compute B[i], states from which acceptance is possible after the remaining
   N-i characters under current D.
3. At each position, retain only characters labeling a transition from F[i]
   into B[i+1]. Intersect both mirrored domains with this support.
4. Repeat until no domain changes. Empty support proves this branch impossible.
5. Branch on a non-singleton mirrored domain with the smallest supported
   alphabet. Try its letters in grammatical-path frequency order.
6. When all domains are singleton, extract every relevant accepting lexical
   path, reconstruct its prose, and run independent admission checks.

Cache domain vectors or their hash plus N, not rendered prefixes. Record
states, propagation rounds, deleted domain values, branch conflicts, and
accepted lexical paths. A capped run is incomplete, never an UNSAT proof.

This leaves all words and all boundaries uncommitted while equality propagates.
An unsupported `after rain` path disappears; other grammatical paths can alter
both the beginning and ending simultaneously. No `afterrain` or `neardusk`
residual is privileged, and neither half is generated by segmenting a finished
reverse tape. Syntax is present before the first character choice.

## Bounded first implementation

Use a shared lexicon with explicit singular/plural subject-verb agreement and
transitive animate/inanimate argument types. Permit one or two ordinary clauses,
subject-first statements, imperatives, and simple questions. Permit at most one
adjective per noun phrase and one optional adjunct per clause. Encode these as
feature states in the automaton, not as pre-rendered sentence banks. Do not
increase the number of adjunct words before validating the solver itself.

First compare against exhaustive enumeration on a tiny grammar at both odd and
even N. Include unequal word boundaries, nonempty palindromic centers, ambiguous
tokenizations, and paths that must disappear only after repeated propagation.
Then recover the 38-letter calibration as a held-out correctness check, reporting
it separately from novel outputs. The immediate research run can target N=39..64
with a strict remote-compute bound; grammar coverage is a separate variable from
solver correctness.

## Candidate and reader gates

For each emitted text, retain its NFA path, lexical provenance, grammar hash,
normalization, letter count, independent two-pointer audit, and a separate
reverse-equality audit. Explicitly check catalogue overlap and prohibited
repetition/mirror construction. An accepting parse establishes only grammar
membership, not English readability or semantic coherence.

Only exact, original, plausible complete prose proceeds to a reproducible blinded
reader package with intact prose and word-shuffled controls in randomized order.
Keep human ratings absent until collected. The API remains gated.
