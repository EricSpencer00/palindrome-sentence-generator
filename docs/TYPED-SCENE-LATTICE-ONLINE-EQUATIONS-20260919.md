# Typed scene lattice with online equations (2026-09-19)

This is a fresh construction lane, distinct from whole-tape products and
residual phrase repair. It assigns semantic roles (subject, verb, object, and
place) from typed inventories, renders complete clauses, and tests the
mirrored character obligation while the two plans are emitted. A final,
independent two-pointer audit is still required; the online test is not used
as a certificate.

The bounded pilot covered 81 scene plans and 13,122 paired renders across
two clause templates. It produced complete English-looking diagnostic prose,
but no exact candidate over the 38-letter benchmark. The JSON run preserves
the actual rendered candidates, role provenance, per-character first failure,
length, SHA-256 forward/reverse audit, and anti-shortcut preflight.

The next construction change is residual obligation propagation across role
boundaries: two-word subject/object bundles will be indexed by their boundary
characters and filtered for agreement before expansion. This changes the
representation rather than repeating the same Cartesian sweep.
