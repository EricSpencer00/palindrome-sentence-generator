# Reader-first control inventory provenance

This nine-item inventory is a hand-curated project control, assembled from
short, widely circulated English palindrome examples. It is not a training or
evaluation corpus, and the project makes no authorship, novelty, or licence
claim for the phrases.

Each entry is retained only after the deterministic constructor verifies its
normalised letter palindrome. The inventory is used to make sentence boundaries
and intentional repetition visible in a presentation control. It must not be
used as evidence that the project generates original, coherent long prose.

Before any archival release of this inventory, each phrase needs a citable
source and a recorded rights determination. Until then, the manuscript and API
refer to it only as a curated catalogue-based control.
