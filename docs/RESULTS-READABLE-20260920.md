# Readable palindrome reference: 2026-09-20

The 286,561-letter remote construction is an exact English-word tile
arrangement, not prose. This separately preserved reference shows the scale
available when readability is treated as the primary constraint:

> T. Eliot, top bard, notes putrid tang emanating. Is sad; I'd assign it a name: gnat dirt upset on drab pot toilet.

It has 85 normalized letters and passes an independent two-pointer audit. It
is known catalogue material, not a new project result, so it is not counted as
progress toward the original-palindrome goal.

The practical tradeoff is explicit: a long lexical palindrome can spend each
new word on its exposed letters; readable prose must spend those same choices
on syntax, agreement, and meaning. Replacing the tile list with fluent prose
therefore requires a new search result, not cosmetic editing of the existing
286,561-letter tape.
