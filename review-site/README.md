# Private readability review page

This is a static Sites deployment of `paper/human_eval_v4_packet/reviewer.html`.
The page contains 52 frozen review items and stores ratings only in the local
browser profile; reviewers export a JSON checkpoint to move work between
browsers or devices. It contains no server-side ratings endpoint.

The source page is copied verbatim so the review instructions, prior-model
score disclosure, 1–5 anchors, pause/resume controls, checkpoint validation,
and local-only privacy behavior stay aligned with the version already reviewed
in the repository. The deployment is owner-private.
