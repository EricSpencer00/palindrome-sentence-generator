# Design

The existing generator uses Archivo and JetBrains Mono, with a white canvas
and purple accents. Preserve that application.

The Panama route is one self-contained HTML file showing only the palindrome
as a continuous paragraph that wraps naturally to the browser width. There is
no numbering, introduction, navigation, or decorative styling. Browser-default
serif text uses an 18px size and 1.6 line height for readable desktop and mobile
layout without horizontal scrolling.
