## Main semantic hypothesis

An aide or an AI acts on plural documents; a second clause uses the same document head as its subject and affects a recipient. This is an explicit actor–object–recipient linkage, rather than a name association. The destroyed-documents branch uses yet; other branches use so. Tense/number and transitive argument slots are licensed. Repeated document nouns are required for the link and remain a soft cost, never a veto.

The declarative budget is 88 actor/action/effect root pairs ×8 document heads ×6 object determiners ×3 anaphoric determiners: 12,672 potential paths. Only two roots pass the sound fixed-edge screen:

- An aide / rips / inspire Diana leaves right debt ni.
- An AI / delivers / revile Diana leaves left debt s.

The 86 rejected roots eliminate 12,384 potential combinations without materializing them. All 96 document/determiner frontiers under the surviving roots then mismatch. All 288 resulting rejected surface proposals are preserved; none is compiled into search. Potential combinations, actual frontier checks and rendered proposals are separately counted. This is a complete negative result for this finite grammar, not an exhaustive natural-language claim.

A concrete failure: after An aide rips, the reverse tail ending inspire contributes ni; plural document subjects end in s, producing nis rather than the nine required by the historical some-men construction. For An AI delivers, the fixed s debt cannot be reconciled with the selected document/determiner forms. Growing the document vocabulary or connector set without changing these frames would repeat the same obstruction.

The four reference variants test the original semicolon plus so/yet/and. Only the original is exact. It is kept as an engine/control check, not counted as a new meaningful result.
